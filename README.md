# not-mario

This is not a copy of the original Super Mario Bros made with Ebiten.

# How To Run

1. Browser

Play at [https://smail1111.github.io/not-mario/](https://smail1111.github.io/not-mario/)

2. Download

Download and run `not_mario.exe`

* Your computer will probably warn you it's dangerous. It's it not.

3. Command Line

If you do not have Go installed, install Go by running `curl -sS https://webi.sh/golang | sh` in your terminal on Linux/WSL/macOS,
or follow the [official Golang installation instructions](https://go.dev/doc/install)

Then run `go run github.com/smail1111/not-mario/program@latest`
